## Overview

Dragonfly Reverb is a set of free open-source reverb plugins offering room, hall, plate, and early-reflection algorithms with rich, musical sound quality.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Dragonfly Reverb** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Four Reverb Types** | Room, hall, plate, and early reflection algorithms in separate plugins |
| **Natural Sound** | FreeverB3-based algorithms tuned for musical, non-metallic decay |
| **Open Source** | GPL-licensed code freely available and actively maintained on GitHub |
| **Low CPU** | Efficient processing suitable for heavy session use |
